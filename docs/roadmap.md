# AshAI Product Roadmap

## Milestone 1: Authentication & Core Setup (Completed)
- JWT Authentication & Spring Security filter chain
- Password hashing & DTO validations

## Milestone 2: AI Integration & Chat Experience (Completed)
- REST AI Assistant endpoint `/api/chat`
- Gemini API integration with intelligent assistant fallback
- Streaming simulation & markdown rendering in dashboard

## Milestone 3: Profile, Settings & Security Workflows (Completed)
- User profile management & password updates
- Theme switching (Light/Dark mode)
- Email verification & Password reset token management

## Milestone 4: Future Expansion
- Multi-modal file upload analysis
- Persistent chat conversation history tables
- Real-time WebSockets streaming API
