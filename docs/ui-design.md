# AshAI UI/UX Design System

## Design Tokens & Typography
- **Primary Font**: `Inter`, sans-serif
- **Color Palette**:
  - Primary Gradient: `linear-gradient(135deg, #6366f1, #4f46e5)`
  - Surface Background: `--bg-main` (`#0f172a` in dark mode, `#f8fafc` in light mode)
  - Card Surface: `--bg-card` (`#1e293b` in dark mode, `#ffffff` in light mode)
  - Accent Color: Indigo/Violet (`#6366f1`)

## Components
- **Chat Composer**: Expanding textarea with auto-resizing height, quick tool buttons, model selection dropdown, and send/stop icons.
- **Markdown Renderer**: Formatted headings, lists, inline code snippets, fenced code blocks with copy-to-clipboard functionality.
- **Theme Switcher**: Instant switching between Dark Mode and Light Mode with CSS custom properties (`var(...)`).
